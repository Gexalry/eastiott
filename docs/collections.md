# Collections

Collections group products for navigation and merchandising.

## Operations

| Action | Tool |
| --- | --- |
| Search | `search_collections` |
| Read one | `get-collection` |
| Create | `create-collection` |
| Update | `update-collection` |
| Add product | `add-to-collection` |

## Conventions

- Smart (rule-based) collections preferred over manual where possible.
- Handle (URL slug) is lowercase-kebab-case.
